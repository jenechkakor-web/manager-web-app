# Manager Web App

Веб-приложение для создания договоров, счетов и ведения реестра менеджеров.

## Локальный запуск

```bash
npm start
```

Приложение откроется на `http://127.0.0.1:4173/`.

Локальный администратор по умолчанию:

```text
Логин: admin
Пароль: admin2026
```

Значения можно изменить через переменные окружения `ADMIN_LOGIN` и `ADMIN_PASSWORD`. Локальные пользователи и данные сохраняются в `.data/` и не попадают в Git.

## Авторизация и права

- Администратор видит весь реестр, редактирует справочник и управляет пользователями.
- Пользователь видит в реестре только собственные договоры и черновики.
- Пароли хранятся только в виде хешей.
- Общий реестр и справочник сохраняются через серверный API, GitHub token в браузере не используется.

## Beget

Производственная версия использует PHP и MySQL. Закрытый файл `api/config.local.php` создаётся только на сервере по примеру `api/config.local.example.php`:

```php
<?php
return [
    'db_host' => 'localhost',
    'db_name' => 'DATABASE_NAME',
    'db_user' => 'DATABASE_USER',
    'db_password' => 'DATABASE_PASSWORD',
    'admin_login' => 'admin',
    'admin_password' => 'INITIAL_ADMIN_PASSWORD',
    'session_name' => 'manager_app_session',
];
```

`admin_login` и `admin_password` используются только при первом создании администратора в пустой базе. После этого пользователи хранятся в таблице `manager_users`.

Таблицы и недостающие поля создаются автоматически при первом запросе к API. Старые записи реестра при миграции закрепляются за первым администратором.

## Деплой

Push в `main` запускает `.github/workflows/deploy-beget.yml` и загружает публичные файлы по FTP. На GitHub должны быть настроены секреты:

```text
BEGET_FTP_SERVER
BEGET_FTP_USERNAME
BEGET_FTP_PASSWORD
```

Файл `api/config.local.php` workflow не загружает и не удаляет.
